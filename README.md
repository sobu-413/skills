# Agent Skills
Personal collection of reusable skills and workflows for AI agents.

## About
This repository is my personal collection of reusable skills for AI agents. Each skill captures instructions and preferences for a particular task or workflow, so I can get more consistent results across projects. The collection will grow as I develop workflows I want to reuse.

## Structure
Each skill lives in its own directory under `.agents/skills/`. Its `SKILL.md` explains what the skill does and provides the instructions the agent needs when using it. Browse the directories to find a skill for the task at hand.

## Using the skills
I use these skills to give AI agents focused context for recurring work, such as writing structured prompts or following a preferred workflow. The skill's own instructions are the source of truth for how it should be applied.
